# Research document and data permissions

The bundled manuscript and supplementary PDF files are user-provided and may be unpublished.
Do not push this project to a PUBLIC repository until the appropriate authors have approved publication.
The application disables anonymous source downloads by default, but public repositories disclose packaged bytes.
Use a private GitHub repository for Render. All people holding the shared workspace secret can access data sessions if their dataset IDs are known; the app is not multi-tenant.
Do not upload regulated, private, or patient data to a public research demonstration.
When deploying to a service, rotate access credentials regularly and protect environment secrets.
